# Try out Obidos

## Demo server
* If you just want to get a feel for @OBIDOS@ User Interface, you can try @OBIDOS_DEMO@ using username 'hndemo' and password 'hndemo'. When prompted for Passphrase, click on "Ask Me Later". You will be able to navigate through the interface, but you will not be able to create anything using this account.
</br>

## Install using docker (easiest)
* To get a Quick Installation of @OBIDOS@ using docker or podman and try out all the features of Obidos, check the sister repo @OBIDOS_DOCKER@.
</br>

## Manually compile from source
* To manually compile @OBIDOS@ from source, please look at the secion @MANUAL_INSTALL@
